# 四类标注规范

类别固定，ID 和英文名不得调整：

| ID | 名称 | 中文 | 建议范围 |
|---|---|---|---|
| 0 | stone | 石头 | 草地、道路上的天然或人造石块、碎石堆中可独立识别的大块石头 |
| 1 | tree | 树木 | 树干及可见树冠整体；离相机很近时框住可见部分 |
| 2 | person | 人 | 任何可见的人体，遮挡时框住可见人体范围 |
| 3 | other_roadblock | 其它路障 | 非前三类、且确实阻挡割草机行进的障碍物，如箱子、锥桶、车辆、路障设施 |

使用贴合可见目标的最小外接矩形。目标被图像边界截断时，框截断后可见范围，不猜测画面外部分。严重模糊或类别无法确认时把图片设为 `uncertain` 并在复核后处理；不把不确定的物体硬归入 `other_roadblock`。树枝、树叶若没有可辨认的树主体，不单独标为树。道路、阴影、普通草地不标框。多个分离目标分别画框；若物体明显属于同一整体，不拆成多个框。空图必须由人工按 N 确认为 negative，直接跳过仍是 unreviewed。
