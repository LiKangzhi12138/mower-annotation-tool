# 多人离线合并规则

1. 各人员分别使用独立输出目录。打包时校验每张源图的 SHA256、标注合法性，并复制原图到新的版本目录；不改源图。
2. 合并先严格校验包版本、类别配置、索引、每张图及每份标注。任何包校验失败则停止。
3. `(source_id, relative_path)` 相同但 SHA256 不同视为来源冲突。不同来源但 SHA256 相同视为重复内容，Master 只保留一份图片。
4. 同一内容的状态、类别和框（忽略 object_id 与更新时刻）完全一致时去重。不同则产生冲突；界面可选择某人的版本，或在叠加预览中编辑框后采用手动修正。未解决冲突禁止发布 Master。
5. Master 在临时目录构建，复制后复核图片和标注，成功才发布到空目标目录。原始包和旧 Master 不修改。`provenance` 记录贡献人员与包 ID，冲突报告记录决策。

注意：如果两人从不同输入目录创建项目，`source_id` 往往不同，重复识别依赖内容 SHA256。仅凭相同文件名不判断同一图片。
