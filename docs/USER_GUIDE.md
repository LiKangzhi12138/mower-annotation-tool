# 标注人员操作指南

1. 在 Conda PowerShell Prompt 运行 `setup.ps1`（首次）和 `run.ps1`。选择图片输入目录与新的空输出目录，点“新建项目”，填自己的标注人员 ID 和数据来源 ID。多人标同一批图时必须约定相同的数据来源 ID。
2. 左侧点图片。中间按 D 进入绘制模式；右侧选择类别，左键拖出框。按 V 进入选择/编辑模式，点框后拖动它，拖角或边缘控制点改尺寸。右侧可改选中框类别或删除。
3. 标注完按 Space 保存并到下一张。空图按 N 确认无目标。存疑图在右侧设 `uncertain`；不适合标注的图设 `exclude`。没有画框而按 Space 跳过的图仍为 `unreviewed`。
4. 按 U 找下一张未标注。点“标注检查”查看进度、未标注清单和问题；双击项目跳转。可导出 JSON/CSV 检查报告。
5. 下次启动选“打开已有标注项目”，指向原输出目录。若输入目录增加图片，点“重新扫描”。请保留原图路径或将原图恢复至原位置。
6. 完成后点“生成便携标注包”，选一个与原图目录分开的包父目录。将整个 `worker_package_vN` 文件夹交给合并人员。
7. 合并人员点“合并标注”，加入至少两个包，先检查，逐条处理冲突，选空目录生成 Master。成功后软件可继续打开 Master 补标。
8. 点“导出 YOLO”，选比例、种子和输出父目录。软件尝试从 `sample_...`、`Snapshot...` 等路径层级识别采集组；必要时用右侧“设置当前图片 group_id”逐张修正。至少需要三个独立组。

快捷键：1–4 选择四类；D 绘制；V 编辑；Space 保存下一张；←/→ 切换；Ctrl+S 保存；Delete 删除；F 适应窗口；N 负样本；U 下一张未标注；Esc 取消；滚轮缩放；鼠标中键平移。

若出现“保存失败”，保持软件打开，检查目标磁盘空间、权限或文件占用，处理后按 Ctrl+S 重试。软件会保留已有 JSON 的 `.bak` 备份。
