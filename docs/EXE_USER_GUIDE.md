# 智能割草机标注工具 Windows 版使用说明

## 启动

把 `MowerAnnotator.exe` 放到电脑上的普通文件夹，双击即可打开。无需安装 Python、Conda、PySide6、Pillow 或 VS Code。首次启动可能稍慢，因为程序需要临时解压运行文件。请勿把标注输出目录设在原始图片目录内部。

## 新建标注项目

1. 点击“选择输入目录”，选择包含原始图片的文件夹。软件递归扫描子目录，不移动或修改原图。
2. 点击“选择输出目录”，选择单独的**空文件夹**存放标注。该目录应与输入目录分开。
3. 点击“新建项目”，填写自己的标注人员 ID。多人标注同一批图时，请使用事先约定的相同“数据来源 ID”。
4. 图片出现在左侧列表后，点击一张开始标注。需要继续旧项目时，点击“打开已有标注项目”，选择其标注输出文件夹。

## 画框与快捷键

右侧选“绘制”模式和目标类别，在图片上按住鼠标左键拖出框。选“选择/编辑”模式后可点选框、拖动位置，或拖动边缘与角的控制点调整尺寸。右侧可修改选中框类别或删除框。

按 `1`/`2`/`3`/`4` 选择石头/树木/人/其它路障；`D` 绘制；`V` 编辑；`Space` 保存并到下一张；`Ctrl+S` 保存；`Delete` 删除选中框；`N` 确认当前图片无目标；`U` 跳到下一张未标注；`F` 适应窗口；`Esc` 取消。鼠标滚轮缩放，中键拖动平移。没有画框而直接跳过的图片仍属未标注。

## 检查与交付

点击“标注检查”查看完成率、未标注图片、错误和重复内容。双击检查项目可跳转至图片。点击“生成便携标注包”，选择一个独立的父目录，软件会生成新版本 `worker_package_vN`；将该**整个文件夹**交给合并人员。

合并人员在“合并标注”中加入多个包，先检查并处理冲突，再选择空目录生成 Master。需要训练数据时点击“导出 YOLO”，设置比例和随机种子。没有明确采集分组的图片须先设置 `group_id`。

## 出现异常

保存失败时请先检查磁盘空间、目录权限以及文件是否被其他程序占用，然后按 `Ctrl+S` 重试。不要删除原标注目录。程序内部异常会显示提示，并尝试将诊断日志写入 `%LOCALAPPDATA%\MowerAnnotator\logs`。如双击后无法启动，请把操作系统版本、EXE 文件及该日志目录中的最新文件交给维护人员；不要修改原始图片或标注 JSON。
